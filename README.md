# AI Engineering

Матеріали дисципліни **«Проєктування систем штучного інтелекту»**.

English title: **AI Engineering: Design of Artificial Intelligence Systems**.

Навчальне навантаження:

- 4 ECTS, 120 академічних годин;
- 8 модулів теоретичної підготовки по 2 академічні години;
- 8 лабораторних занять по 2 академічні години;
- 88 годин самостійної роботи;
- підсумковий контроль — залік.

Курс розробляється навколо практичного проєктування AI-систем. Теоретичні рішення перевіряються у лабораторних роботах на нейтральному `training-project`, а реальні проєкти викладача використовуються як джерела перевірених інженерних кейсів.

Узгоджені англійські терміни та їхні українські відповідники наведено в [глосарії](GLOSSARY.md).

Навігація за модулями буде додаватися після затвердження тематичного плану.
